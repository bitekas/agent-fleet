# `NotImplementedError: Algorithm 'RS256' could not be found` at the first

# left to a transitive install: the failure is a runtime one, inside the first
# real call, and looks nothing like a missing package.

# the fleet's CI, which installs from this file - gets the same signing stack each
# time. To move: bump these four together and re-run gsheets.test.py.
